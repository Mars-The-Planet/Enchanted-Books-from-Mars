<center><p style="text-align: center;">This mod gives every enchanted book its own unique texture, making it much easier to find the one you need at a glance. It is based on a <a href="https://modrinth.com/resourcepack/different-textures-for-enchanted-books">resource pack</a> I previously made, which requires an additional mod implementing CITs to work. With this mod, you do not need to download a resource pack and depend on separate CIT mods that may vary between Minecraft versions and mod loaders.</p></center>

<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or by editing the JSON file <code>config/ebooks.json</code> in your profile folder. If you're using Fabric and want to adjust the config values in-game, you'll need to install <a href="https://modrinth.com/mod/modmenu">Mod Menu</a>.</p>
<center>
<p style="text-align: center;"><b>turned_on</b> - Turn the enchanted book textures from this mod on and off</p>
